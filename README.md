# Web Services Course Projects (CSE 341)

This repository contains coursework, assignments, and API services developed for the **Web Services** curriculum. The repository focuses on building modern, secure, and production-ready RESTful web services using Node.js, Express, MongoDB Atlas, and cloud deployment platforms.

---

## 🎯 Course Objectives & Core Competencies
- **RESTful API Design:** Implementing standard HTTP methods, clean routing, and predictable resource endpoints.
- **MVC Architecture:** Enforcing strict separation of concerns among models/database queries, route definitions, and controllers.
- **Database Integration:** Working with cloud NoSQL databases (MongoDB Atlas) using native drivers.
- **Security & Environment Hygiene:** Managing environment secrets with `.env` files and preventing credential leakage via `.gitignore`.
- **Cloud Deployment:** Deploying backend services to PaaS platforms (such as Render) with continuous deployment (CD).
- **API Testing & Verification:** Automating and documenting HTTP requests using REST Client files (`.rest`).
